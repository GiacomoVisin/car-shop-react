# 🚗 Car Shop React

Un'applicazione web moderna e dinamica sviluppata in **React** per la gestione e l'esplorazione di un catalogo di automobili. Questo progetto permette agli utenti di navigare tra diversi veicoli, visualizzarne le specifiche tecniche e interagire con i dati in modo fluido.

---


## ✨ Caratteristiche Principali

- **Catalogo Dinamico:** Visualizzazione dei veicoli disponibili con dettagli e informazioni tecniche.
- **Routing Avanzato:** Navigazione fluida e multipagina gestita tramite **React Router DOM v7**.
- **Chiamate API Asincrone:** Integrazione con **Axios** per il recupero dei dati da un server o API backend.
- **Developer Experience Moderna:** Configurato con **Vite** per un hot-reload istantaneo e build ottimizzate.

---

## 🛠 Tecnologie Utilizzate

Il progetto sfrutta un set di strumenti frontend moderno:

- **React (^19.3.1)** - Libreria principale per la costruzione dell'interfaccia utente.
- **React Router DOM (^7.18.5)** - Per la gestione del routing lato client.
- **Axios (^1.21.1)** - Client HTTP per le richieste di rete.
- **Vite (^8.3.6)** - Build tool e dev server ultra-rapido.
- **ESLint** - Per il controllo della qualità e la formattazione del codice.

---

Prima di procedere, assicurati di avere installato sul tuo computer:
